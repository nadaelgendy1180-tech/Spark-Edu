# SPEAK — تحديث الاسم والواجهة وصورة دكتورة ندا الجندي

## الملفات الجاهزة لرفعها إلى GitHub
فكّ ضغط الملف، ثم ارفع محتوى المجلدات كما هو إلى **جذر** المستودع الحالي https://github.com/nadaelgendy1180-tech/Spark-Edu.

1. `src/App.tsx` — تغيير اسم المنصة في واجهة الدخول ولوحة المدير والمستخدم، وإضافة بطاقة «فكرة وإعداد دكتورة ندا الجندي» وتحسين ظهور صورتها، مع الاحتفاظ بتسجيل الخروج وزر واتساب.
2. `src/styles.css` — إطار صورة احترافي، عرض الوجه بوضوح، توافق الموبايل والتابلت والكمبيوتر، دعم تقليل الحركة.
3. `src/InstallAppButton.tsx` و`src/pwa.ts` و`src/main.tsx` — اسم SPEAK في التثبيت ورسائل PWA.
4. `src/export.ts` — اسم SPEAK ونسبة الفكرة والإعداد للدكتورة في مستند Word المُصدَّر.
5. `index.html` و`public/manifest.webmanifest` و`public/sw.js` و`public/favicon.svg` — عنوان الموقع واسم التطبيق والشعار والتحديث الصحيح للكاش.
6. `package.json` — تغيير اسم حزمة المشروع فقط إلى `speak-platform` مع **الإبقاء على جميع الاعتمادات والسكريبتات الأصلية**.
7. `public/center-photo.jpeg` و`public/center-logo.jpeg` — الصور الأصلية دون تعديل محتواها، لإظهارها عند استبدال ملفات المستودع حتى لو لم تكن موجودة.
8. `public/app-icon-192.png` و`public/app-icon-512.png` و`public/apple-touch-icon.png` — أيقونات التطبيق الحالية المحفوظة، لا تغيير للصور الرسومية داخلها.
9. `tests/speak-branding.test.mjs` — اختبار تحديث الاسم وتسجيل الخروج وواتساب وظهور الصورة.

## ما لا يجب تعديله
- Firebase Project ID سيظل `speak-d6e7f`، ولا تُحذف مجموعة users أو أي بيانات في Firestore.
- قيم `VITE_FIREBASE_*` على Vercel تبقى كما هي.
- رابط الموقع الحالي `https://spark-edu.vercel.app` لا يتغير تلقائيًا. إذا أردت رابطًا جديدًا، غيّره من لوحة Vercel > Settings > Domains بعد النشر.
- المستودع الحالي GitHub يظل باسم Spark-Edu ما لم تغير اسمه أنت، وهذا لا يؤثر في اسم SPEAK المعروض.
- مفتاح Firebase الإداري وكلمات المرور لا يجب رفعهما إلى GitHub.

## خطوات النشر
1. احتفظ بنسخة من الملفات الحالية.
2. فكّ ضغط ملف ZIP وارفع محتوياته إلى GitHub `main` داخل المسارات الصحيحة مع استبدال الملفات.
3. اضغط Commit changes.
4. افتح Vercel > Deployments وتأكد أن آخر نشر أصبح Ready.
5. حدّث الصفحة مرة واحدة، وجرّب تسجيل دخول المدير، تسجيل الخروج، واتساب، تقييم الأطفال، استيراد الأهداف، وتثبيت التطبيق.
6. للأجهزة التي ثبتت الاسم القديم، قد يحتاج ظهور اسم SPEAK إلى تحديث التطبيق المثبّت أو إعادة تثبيته، حسب المتصفح ونظام التشغيل.

## تنبيه
هذا التحديث مبني على أحدث نسخة مشروع متاحة من الملفات السابقة في المحادثة، وليس على تأكيد أحدث Commit في المستودع. الصورة الأصلية لم تخضع لأي تعديل لملامح الوجه؛ التحسين خاص بإطار العرض والقصّ المتجاوب.
